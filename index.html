Takies

A private publishing tool for the Mysterious Talkies YouTube channel.

Takies is a small automation tool built and used by one person: the owner of the YouTube channel Mysterious Talkies. It prepares short videos about how ancient humans lived, and publishes them to that same channel.

What it does

  • Takes a written script from the owner's own content list.
  • Turns the script into narration with a text-to-speech voice, and adds free stock imagery and captions.
  • Renders a vertical short video on a schedule.
  • Uploads the finished video to the owner's own YouTube channel using the YouTube Data API v3.

Who uses it

Only the owner of the channel. Takies has no sign-up, no accounts, no public interface and no other users. It never asks any other person for a Google account.

What it accesses

With the owner's permission, Takies can upload videos to the owner's own channel. It does not read other channels, comments, subscribers, messages, or any other Google user data.
