Privacy policy

Takies · a private publishing tool for the Mysterious Talkies YouTube channel

This policy explains what the Takies tool ("the tool") does with data. The tool is operated by one person, the owner of the YouTube channel Mysterious Talkies, and is used only by them.

Google user data

The tool asks the owner's Google account for one permission: the ability to upload videos to the owner's own YouTube channel (the youtube.upload scope of the YouTube Data API v3).

With that permission the tool:

  • uploads finished video files to the owner's own channel;
  • sets the video's own title, description, tags and privacy setting.

The tool does not read, store or process any other Google user data. It does not access other people's channels, comments, subscriber lists, playlists, watch history, email, contacts, files or calendars. It does not use Google user data for advertising, profiling or resale, and does not transfer it to anyone.

How credentials are stored

The owner's authorization token is kept in the private repository settings of the owner's own GitHub account, as an encrypted secret used only by the tool's automated job. It is never displayed, published or shared, and it is not stored in this website or in any browser.

Other services

Free stock photographs are requested from the Pexels API. No personal data is sent to Pexels; only a search term is. No analytics, advertising or tracking services are used, and this site sets no cookies.

Data retention and deletion

Uploaded videos stay on the owner's YouTube channel until the owner deletes them. The authorization can be withdrawn at any time by removing the tool's access at myaccount.google.com/permissions, and the stored token can be deleted from the owner's repository settings. Once access is removed, the tool can no longer act on the channel.

Children

The tool is not directed at children and is not offered to any other user.

Changes

If this policy changes, the new version will be posted on this page with a new date.
